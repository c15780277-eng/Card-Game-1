Narco Cards: The Gathering — Prototype

Dies ist ein funktionsfähiger Prototyp im Branch feature/full-game. Er enthält:

- index.html: Entry-Point und einfache UI
- css/style.css: Styles
- js/game.js: Spiel-Engine, Deckbuilder, Shop, einfache KI

Wie spielen:
- Öffne index.html im Browser.
- Verwende 'Deckbuilder' um Karten aus deiner Sammlung ins Deck zu packen.
- Klicke 'Spielen' um gegen die KI anzutreten.

Persistenz: Fortschritt wird im lokalen Storage gespeichert (ncg_v1).

Zukünftige Aufgaben:
- Weitere Karten und Grafiken
- Verbesserte Kampfmechanik (Kampfpos., Angriffsziele)
- Sounds, Animationen
- Tests und Balancing
